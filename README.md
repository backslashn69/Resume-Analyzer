# Resume-Analyzer
AI Resume Analyzer
An AI-powered web application that helps job seekers optimize their resumes for specific roles by analyzing them against job descriptions using Large Language Models.
Features

Multi-format support — PDF, Word Document and image screenshots
ATS match scoring — percentage match against job description
Keyword gap analysis — identifies missing keywords instantly
Actionable improvements — specific suggestions to strengthen your resume
OCR support — reads text from screenshots using Tesseract
Multi-page support — upload multiple files for multi page resumes
Consistent scoring — temperature controlled AI for reliable results

Tech Stack

Python
LangChain
Groq API — LLaMA 3.3 70B
PyPDF2
python-docx
Tesseract OCR
Streamlit

Use Cases

Optimizing resume for specific job applications
Identifying ATS keyword gaps before applying
Getting expert career coach feedback instantly
Comparing resume strength across multiple job descriptions
